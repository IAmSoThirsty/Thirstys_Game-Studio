# Thirsty's Game - Energy Empire

## Overview

**Thirsty's Game** is a God-tier addictive incremental/idle game built with cutting-edge architecture. It features a robust Entity Component System (ECS), multiple progression systems, and beautiful visual effects.

## 🎮 Game Features

### Core Gameplay
- **Click-based Generation**: Click the central orb to generate energy
- **Idle Progression**: Automated producers generate resources passively
- **Resource Chain**: Convert Energy → Crystals → Essence
- **Critical Hits**: Chance for bonus rewards on clicks

### Progression Systems
- **Producers**: 4 different energy generators with exponential scaling
- **Converters**: Transform lower-tier resources into higher-tier ones
- **Upgrades**: 5+ permanent upgrades that enhance gameplay
- **Achievements**: Unlock rewards by reaching milestones
- **Statistics Tracking**: Detailed stats for all your progress

### Visual Excellence
- **Particle Effects**: Beautiful particle bursts on interactions
- **Smooth Animations**: 60 FPS gameplay with fixed timestep
- **Color-coded UI**: Clear visual hierarchy with F2P-friendly theme
- **Multiple Tabs**: Organized interface for different game aspects

## 🏗️ Architecture

### Entity Component System (ECS)

The game uses a production-ready ECS architecture:

```
┌─────────────────────────────────────────┐
│           Game Engine                   │
│  - Fixed Timestep Loop                  │
│  - Event System                         │
│  - State Management                     │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│              World                      │
│  - Entity Management                    │
│  - System Orchestration                 │
└─────────────────┬───────────────────────┘
                  │
        ┌─────────┴──────────┐
        │                    │
        ▼                    ▼
  ┌──────────┐         ┌──────────┐
  │ Entities │         │ Systems  │
  │ + Comps  │◄────────│ Process  │
  └──────────┘         └──────────┘
```

### Components (Data)
- **Transform**: Position and scale
- **ResourceProducer**: Generates resources over time
- **ResourceConverter**: Converts one resource to another
- **ClickGenerator**: Handles click-based generation
- **Upgrade**: Purchasable permanent enhancements
- **Achievement**: Unlockable milestones with rewards
- **Visual**: Rendering information
- **Particle**: Particle effect data
- **GameResources**: Central resource pool
- **Stats**: Player statistics

### Systems (Behavior)
- **ResourceProductionSystem**: Updates all producers
- **ResourceConversionSystem**: Handles resource conversion
- **ParticleSystem**: Updates particle effects
- **CooldownSystem**: Manages cooldowns
- **StatsTrackingSystem**: Records player statistics
- **AchievementSystem**: Checks and unlocks achievements

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/IAmSoThirsty/Thirstys_Game-Studio.git
cd Thirstys_Game-Studio

# Install dependencies
pip install -r requirements.txt

# Run the game
python main.py
```

### Controls

| Key | Action |
|-----|--------|
| **Mouse Click** | Generate energy by clicking the orb |
| **Q/W/E/R** | Quick purchase producers 1-4 |
| **1** | Main screen |
| **2** | Upgrades screen |
| **3** | Achievements screen |
| **4** | Statistics screen |
| **S** | Save game |
| **P** | Pause game |
| **ESC** | Quit game |

### Tips for New Players

1. **Start Clicking**: Build up initial energy by clicking the orb
2. **Buy First Producer**: Get your first Solar Panel (10 energy)
3. **Go Idle**: Producers generate resources automatically
4. **Upgrade Path**: Focus on production upgrades early
5. **Achievements**: Check achievements for bonus multipliers
6. **Save Often**: Press S to save your progress

## 📊 Game Mechanics

### Resource Types

1. **Energy** (Primary)
   - Generated by clicking and producers
   - Used to purchase producers and upgrades
   - Base currency of the game

2. **Crystals** (Secondary)
   - Converted from Energy (100:1 ratio)
   - Used for advanced upgrades
   - Unlocked via Energy Crystallizer

3. **Essence** (Tertiary)
   - Converted from Crystals (10:1 ratio)
   - Future high-tier content
   - Unlocked via Crystal Refinery

### Producers

| Name | Rate | Initial Cost | Type |
|------|------|--------------|------|
| Solar Panel | 1.0/s | 10 | Energy |
| Wind Turbine | 5.0/s | 50 | Energy |
| Fusion Reactor | 25.0/s | 500 | Energy |
| Crystal Mine | 0.1/s | 1000 | Crystals |

Each producer:
- Starts at level 0
- Cost increases by 15% per level
- Production scales with level
- Can be upgraded indefinitely

### Upgrades

- **Click Power I/II**: Multiply click generation
- **Production Boost**: Double all production
- **Efficiency**: Improve converter efficiency
- **Critical Strike**: Increase critical hit chance

### Achievements

Achievements provide permanent multiplier bonuses:
- First Steps: +10% energy multiplier
- Energy Baron: +20% energy multiplier
- Clicker: +5% global multiplier
- Dedicated: +10% global multiplier
- Crystal Collector: +15% crystal multiplier

### Adding New Content

#### Adding a Producer

```python
self._create_producer(
    name="New Producer",
    resource_type="energy",
    base_rate=100.0,
    cost=10000.0,
    x=100,
    y=400
)
```

#### Adding an Upgrade

```python
self._create_upgrade(
    name="Super Boost",
    description="Triple production",
    cost=50000,
    resource_type="energy",
    effect_type="production_multiplier",
    effect_value=3.0
)
```

#### Adding an Achievement

```python
self._create_achievement(
    name="Big Milestone",
    description="Earn 1M energy",
    req_type="resource_total",
    req_value=1000000.0,
    target="energy",
    reward_type="multiplier",
    reward_value=1.5,
    reward_target="energy"
)
```
